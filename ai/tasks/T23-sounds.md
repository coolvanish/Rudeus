## Goal
Five short, original sounds (we generate them, so they are ours: CC0) play on the character's events: placed,
jumped, landed, fell, blocked. Generated by a stdlib Python script (no download, no third-party asset), bundled as
WAV in the APK, played through `SoundPool` from a tiny host class that the Activity wraps around the slot's
`onCharacterEvent`. Nothing in `:shared` or `:core` changes; the AR view does not know sounds exist.

## Contract
### scripts/gen-sounds.py
`python3 scripts/gen-sounds.py androidApp/src/main/assets/sounds` writes the five files deterministically (fixed
seed / pure functions, so re-running yields byte-identical files). Sketch: place = two-note rising chime (sine,
660 -> 880 Hz, 2 x 120 ms, soft attack); jump = upward sweep 300 -> 900 Hz, 180 ms, triangle wave; land = low thud
(sine 120 Hz with fast exponential decay + 20 ms noise burst, 160 ms); fall = downward sweep 800 -> 200 Hz, 350 ms,
quieter at the end; blocked = short "bonk" (square 220 Hz, 90 ms, hard decay). Peak <= -3 dBFS, 5 ms fade in/out so
nothing clicks. Print each file's duration and size.

### Sounds.kt
```kotlin
// HAND-REVIEW: T23 — SoundPool wrapper; never throws into the frame loop, no-op until loaded.
class Sounds(context: Context) {
    fun play(event: CharacterEvent)   // PLACED -> place, JUMPED -> jump, LANDED -> land, FELL -> fall,
                                      // BLOCKED -> blocked, RESPAWNED -> place (soft), everything else -> nothing
    fun release()
}
```
- `SoundPool.Builder().setMaxStreams(3)` with `AudioAttributes` USAGE_GAME / CONTENT_TYPE_SONIFICATION.
- Loads from `assets/sounds/*.wav` via `AssetFileDescriptor`; an id that has not finished loading is skipped (track
  `OnLoadCompleteListener`), so the first event can be silent but never blocks or throws.
- Rate-limit: the same event plays at most once per 150 ms (a BLOCKED edge can repeat quickly when re-tapping).
- Volume 0.8 for place/jump/land, 0.6 for fall/blocked.

### MainActivity.kt
```kotlin
val sounds = remember { Sounds(applicationContext) }
DisposableEffect(Unit) { onDispose { sounds.release() } }
App(
    arView = { modifier, slot ->
        // HAND-REVIEW: T23 — sounds ride on the slot's event callback; the AR view is unchanged.
        val withSound = remember(slot) { slot.copy(onCharacterEvent = { e -> sounds.play(e); slot.onCharacterEvent(e) }) }
        WithCameraPermission(modifier) { RudeusArView(modifier, withSound, scanner = host) }
    }, ...
```
`ArSlot` is a data class whose `equals` is identity; `remember(slot)` keys on that identity, so a new slot gives a
new wrapper and an unchanged slot keeps the same one.
